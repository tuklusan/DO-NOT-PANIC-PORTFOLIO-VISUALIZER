This build shows floating ticker tapes, finance headlines, exchange-photo backgrounds, and market-aware overlays.
Release 1.0 retains the one-symbol-at-a-time runtime cadence, local AppData storage model, and configurable custom-background folder support established during the beta cycle.
Release 1.0 keeps finance news available through RSS by default, with optional OpenAI-compatible AI summarization when the user configures a provider, model, and key.
Release 1.0 is intended as the first non-prerelease public baseline after the beta7 installer fallback.

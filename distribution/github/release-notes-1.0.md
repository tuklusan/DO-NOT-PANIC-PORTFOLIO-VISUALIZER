# DO NOT PANIC PORTFOLIO VISUALIZER 1.0

The first public, non-prerelease release of DO NOT PANIC PORTFOLIO VISUALIZER
turns delayed market data into a cinematic Windows stock market dashboard with
custom portfolio ticker tapes, floating graph cards, global markets, macro
indicators, financial news, and rotating city or exchange backgrounds.

## Before installing

**This release is unsigned.** If the installer came from this official GitHub
Release and its SHA-256 matches the checksum below, choose **More info** and
then **Run anyway** if Microsoft Defender SmartScreen displays "Windows
protected your PC." The source is publicly available for inspection.

The release includes a VirusTotal advisory report after release finalization.
VirusTotal is a third-party multi-engine signal, not a certification, warranty,
or guarantee of safety.

## Highlights

- Four configurable stock and ETF ticker-tape lanes with blue, green, and red
  quote-update signals
- Up to 16 floating graph cards for the largest portfolio movers
- Macro-market and independent Global Markets ribbons
- RSS financial news by default, plus optional AI-styled Douglas
  Adams-inspired Vogon haiku or classical Shakespearean summaries
- Built-in, managed-download, or user-selected rotating backgrounds
- Responsive windowed, maximized, and fullscreen modes with F11, double-click,
  and Esc controls
- Self-contained all-users Windows installer with Desktop and Start shortcuts
- Protected local API-key storage and clean RSS fallback when AI is unavailable

## Important limitation

This is an artistic visualization for education and entertainment. Quotes are
delayed by at least 15 minutes and may be unavailable or inaccurate. It is not
a trading terminal, financial-planning application, portfolio-accounting
system, alerting platform, or dependable financial monitoring tool.
